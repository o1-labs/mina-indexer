# Follow-up: configless devnet image (live devnet, genesis `3NLatMgZ`)

Tracked from PR #11 (mainnet + mesa-mut shipped). File this as a GitHub issue.

## Goal
Add a configless `mina-indexer:<tag>-devnet` image that indexes the **live devnet** —
genesis `3NLatMgZHkVsjqppRAB2jBySpcXwV9eZzUNkJ5g18V1TLUAqRrdT`.

## Why it's not a drop-in
Live devnet is a **hardfork** network. Unlike mesa (whose genesis `3NKQttwm` was a real produced
block the indexer just embeds), devnet's genesis is off the produced chain, so it needs the full
mesa-style genesis wiring — a self-contained bring-up.

> The daemon image `gcr.io/o1labs-192920/mina-daemon:3.4.0-alpha1-22d9374-*-devnet` is a
> **preflight for a *different*, upcoming fork** (config forks at `296371`/slot `445860`, ledger
> `jy1wjiJg`), **not** the live chain (live `296371` carries `genesis_state_hash=3NLatMgZ`, slot
> `445619`). Don't use that daemon's genesis for the live image.

## Facts already established
- **Block source**: `gs://mina_network_block_data`, `devnet-<height>-<hash>.json` (public, plain
  HTTPS). `ops/block-pull.sh` already handles these; live blocks carry `genesis_state_hash=3NLatMgZ`.
- **Genesis ledgers exist**: `gs://o1labs-gitops-infrastructure/devnet/devnet-state-dump-*.json.gz`
  and `.../devnet/devnet-ledger.json`.
- **Indexer mechanics** (`rust/src/state/mod.rs:315-393`): witness tree roots at the genesis block
  and connects children by `previous_state_hash == root.state_hash`. `genesis_state_hash` from
  blocks is a *separate* staking-ledger partition key (`state/mod.rs:1319` special-cases
  MAINNET/HARDFORK — needs a devnet arm). `(version,chain_id,genesis)` dispatch is keyed by
  `--genesis-hash` in `rust/src/bin/mina-indexer.rs:389`.

## Work (mirror the mesa-mut changeset)
1. Identify the live-devnet **genesis root**: the in-chain block whose `state_hash` the first
   post-fork block chains to via `previous_state_hash` (mesa used `3NKQttwm@297735`). Download it,
   **empty its `staged_ledger_diff`** so it applies as a no-op.
2. Embed it: `rust/data/genesis_blocks/devnet-<len>-<hash>.json` + `GenesisBlock::new_devnet`.
3. **Genesis ledger**: pick the matching `o1labs-gitops-infrastructure/devnet` state dump (ledger
   hash must match the root block); `GenesisLedger::new_devnet` and/or bake it gzipped into the image.
4. `DEVNET_*` constants in `rust/src/constants.rs` (genesis hash, prev hash, length, slot, vrf,
   ledger hash, timestamp, `DEVNET_CHAIN_ID`), `ChainId::devnet()`, `GenesisVersion::devnet()`,
   `IndexerVersion::devnet()`, dispatch arm, and the `state/mod.rs:1319` staking arm.
5. Re-add the devnet image: `ops/entrypoints/devnet.sh`, `indexer-entry-devnet` +
   `dockerImage-devnet` in `flake.nix` (bake the ledger gz), and the `devnet` leg in
   `.github/workflows/oci-image.yml`. `block-pull` start height = post-fork genesis + 1.
6. **Verify**: `docker run` configless → roots at the devnet genesis, ingests `devnet-*`, ledger
   hashes validate.
